# End-to-End Test Automation Framework

##  Overview

This project is a scalable and maintainable end-to-end (E2E) test automation framework developed using Selenium WebDriver, Cucumber (BDD), and Java. It supports behavior-driven development (BDD) to ensure collaboration between QA, development, and business stakeholders.

The framework is designed to automate functional testing of web applications, provide detailed test reports, and support parallel execution.

---

##  Tech Stack

- **Programming Language**: Java
- **Automation Framework**: Selenium WebDriver
- **BDD Framework**: Cucumber
- **Build Tool**: Maven 
- **Test Runner**: JUnit 
- **Reporting**: Cucumber Reports 
- **Browser Drivers**: ChromeDriver, GeckoDriver (Firefox)
